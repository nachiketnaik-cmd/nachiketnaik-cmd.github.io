# nachiketnaik-cmd.github.io

My personal portfolio site, built with plain HTML, CSS and JavaScript and hosted on GitHub Pages.

- `index.html`: home page (hero, timeline, experience, tools, research, writing, contact)
- `equity-research.html`, `research.html`, `writing.html`: inner pages
- `posts/`: blog posts
- `style.css` and `script.js`: shared styling and behaviour (menu, scroll effects)
- `images/`: photo and project images

To add a project or report, copy an `<article class="card">` block and edit it.
